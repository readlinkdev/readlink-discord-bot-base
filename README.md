# Discord Bot Base

A minimal and modern foundation for building Discord bots with TypeScript.

Built by **readlinkdev** with a focus on clean architecture, type safety, and extensibility.

> ⚠️ **Early Version**
>
> This is the first version of the base. APIs, structure, and features may change as the project evolves.

## Features

- TypeScript
- Discord.js
- Dynamic command, event, and component loaders
- Custom component routing with dynamic parameters
- Built-in logger
- Environment variable validation with Zod
- Drizzle ORM
- Development and production command registration
- ESM / modern Node.js support

## Requirements

- Node.js 24+
- pnpm
